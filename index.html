ALCANCE DEL PROYECTO

Este plan se basa en el Manual de Usuario v1.1, actualizado el 7 de octubre de 2026. El sistema de administración de panadería descrito allí usa Windows Forms y SQL Server Express para guardar inventario, ventas, clientes, cuentas por pagar y proyecciones de producción. Durante cuatro semanas vamos a ordenar su alcance, preparar ejemplos guiados y revisar los controles necesarios. Este documento no desarrolla ni modifica el programa.

InventarioRegistro de productos terminados e insumos, cantidades, unidades, precios, ubicación y vencimiento; control de entradas y salidas.
VentasIdentificación del cliente por NIT, registro de clientes nuevos, selección de productos, cálculo de importes y descuento automático de existencias al confirmar la venta.

La información confirmada se almacenará en la base de datos. La producción marcada como real aumentará el inventario; los escenarios utilizados para simulación no modificarán las existencias. Las proyecciones se elaborarán con los costos, cantidades y demanda estimada ingresados por el usuario.

Límites del proyecto

Esta versión no contempla facturación electrónica, contabilidad completa, procesamiento de pagos bancarios, cálculo automático de nómina, consumo automático de ingredientes mediante recetas, conversión de filas de pan a unidades, anulación de ventas ni pronósticos estadísticos de demanda. Tampoco incluye curvas de indiferencia o utilidad marginal.

Las gráficas y los indicadores económicos apoyarán el análisis académico y la toma de decisiones, bajo los supuestos del modelo utilizado; no garantizarán resultados futuros.

Vamos a planificar una revisión guiada de los cinco módulos descritos: Inventario (productos terminados e insumos y movimientos manuales), Ventas (carrito y descuento del stock al confirmar), Clientes (registro por NIT e historial), Cuentas por pagar (proveedores, nómina, gastos fijos y abonos) y Proyecciones (escenarios de producción e indicadores de microeconomía). Los registros confirmados se guardan en la base Panadería de SQL Server. La propuesta define quién revisa cada dato y describe casos de ejemplo.

Quedan fuera del plan programar o modificar el sistema, cambiar la base de datos o registrar movimientos reales. Tampoco se propone que el sistema emita facturas electrónicas, procese cobros bancarios, verifique NIT en la SAT, descuente insumos con recetas, genere cuentas recurrentes o pronostique la demanda; el manual indica que esas funciones no están incluidas.

PLANTEAMIENTO DEL PROBLEMA

La operación de una panadería requiere controlar las existencias de productos terminados e insumos, registrar las ventas, mantener información de los clientes y dar seguimiento a las obligaciones de pago. Cuando estos registros se administran de forma manual o en archivos separados, resulta difícil disponer de información actualizada y relacionar la producción con las ventas y los costos.

La falta de integración puede ocasionar diferencias entre las existencias físicas y las registradas, ventas de productos sin disponibilidad y dificultades para consultar el historial de compras o conocer los saldos pendientes con proveedores y empleados. Esto limita la capacidad de organizar las actividades diarias y tomar decisiones con información consistente.

Además, conocer la cantidad producida no es suficiente para evaluar el desempeño de la panadería. Es necesario analizar cómo cambia la producción al variar el número de trabajadores, cuál es su productividad y cuántas unidades deben venderse para cubrir los costos. Sin registros comparables y herramientas de análisis, estos aspectos pueden quedar sujetos a estimaciones poco fundamentadas.

Para el caso académico de este proyecto, se plantea la necesidad de un sistema que centralice el inventario, las ventas, los clientes y las cuentas por pagar, e incorpore escenarios y gráficas de producción. Mediante los datos ingresados, permitirá aplicar conceptos de Microeconomía como el producto físico total, medio y marginal, las etapas aproximadas de producción y el punto de equilibrio.

OBJETIVOS

Objetivo General

Desarrollar un sistema de escritorio para una panadería, utilizando C#, Windows Forms y SQL Server Express, que integre el control de inventario, ventas, clientes y cuentas por pagar, e incorpore herramientas de análisis microeconómico para apoyar la gestión y la evaluación de escenarios de producción.

Objetivos Específicos

  • Diseñar el sistema mediante una arquitectura de tres capas—Entidades, Lógica de Negocio y Presentación— que facilite la organización y el mantenimiento del código.
  • Implementar el registro de productos terminados e insumos, con control de cantidades, unidades, precios, ubicación, vencimiento y movimientos de inventario.
  • Integrar el registro de ventas con la identificación de clientes por NIT, el cálculo de importes y el descuento automático de existencias al confirmar cada operación.
  • Permitir el registro de obligaciones con proveedores, nóminas y gastos fijos, así como el seguimiento de abonos y saldos pendientes.
  • Facilitar la consulta de información de clientes y de su historial de compras por fecha y NIT.
  • Incorporar escenarios de producción para calcular el producto físico total, medio y marginal, las etapas aproximadas de producción y el punto de equilibrio, mediante datos y supuestos definidos por el usuario.
  • Representar gráficamente la producción, la productividad y la relación entre ingresos y costos para facilitar la interpretación de los resultados.
  • Almacenar la información en la base de datos Panadería y documentar el uso del sistema mediante un manual de usuario.

JUSTIFICACIÓN

El desarrollo de este proyecto se justifica por la necesidad de integrar la información operativa de una panadería en una herramienta que facilite el control de inventario, el registro de ventas, la consulta de clientes y el seguimiento de cuentas por pagar. Disponer de estos datos en una misma aplicación permite consultar las operaciones y reducir la dependencia de registros dispersos.

El sistema contribuye al control de existencias mediante el registro de entradas, salidas y producción real, así como el descuento automático de productos al confirmar una venta. También permite consultar el historial de compras y los saldos pendientes, proporcionando información útil para organizar las actividades diarias de la panadería.

Desde la perspectiva académica, el proyecto vincula el desarrollo de software con la aplicación de conceptos de Microeconomía. El módulo de Proyecciones permite comparar escenarios de producción y analizar el producto físico total, medio y marginal, las etapas aproximadas de producción y el punto de equilibrio. Sus gráficas facilitan la interpretación de los resultados y la comprensión de la relación entre trabajadores, producción y costos.

El uso de C#, Windows Forms, una arquitectura de tres capas y SQL Server Express permite organizar las responsabilidades del programa y conservar la información registrada. Esta estructura facilita el mantenimiento y ofrece una base para incorporar nuevas funciones.

En consecuencia, el proyecto aporta una herramienta de apoyo al control administrativo y un recurso para el aprendizaje práctico. Sus resultados pueden orientar la evaluación de alternativas de producción, considerando que las proyecciones dependen de la calidad de los datos ingresados y de los supuestos utilizados.

LA EMPRESA: EL HORNO DE LA DOS

Origen y Datos Generales

Fundada en 1986, inició como un pequeño negocio familiar que, gracias a sus recetas artesanales, se posicionó rápidamente como la panadería más famosa del barrio. Debido a su éxito a lo largo de los años, la demanda diaria actual ha superado la capacidad de gestión manual. La transición generacional en la dirección del negocio exige una modernización urgente, buscando implementar un software que permita mejorar los procesos de producción, control de inventario, y pago a proveedores y acreedores.

  • • Nombre: El Horno de la Dos
  • • Ubicación: Zona 2, Ciudad de Guatemala
  • • Número de Empleados: 20 colaboradores directos.

Estructura Empresarial

El liderazgo está a cargo del hijo del fundador (Gerente General), quien impulsa la modernización y expansión B2B (distribución a otras zonas). Las áreas clave se dividen en:

  • • Administración y Finanzas: Gerencia, Tesorería (flujo de caja diario) y Contabilidad. Centralizada en la Gerencia General, con enfoque en modernización y trabajo por objetivos.
  • • Producción: Liderada por un jefe de Producción.
  • • Ventas y Mostrador: Atención al cliente y cajas.
  • • Logística y Bodega: Encargados de inventario y equipo de distribución externa.

PROPÓSITO

Modernizar la administración de "El Horno de la Dos" para soportar el aumento de la demanda diaria y facilitar su futura expansión comercial. El propósito central es que la gerencia deje de tomar decisiones empíricas y comience a basar su estrategia en el análisis de datos exactos proporcionados por el sistema.

A través del módulo de gráficas de proyecciones, la empresa podrá visualizar la relación directa entre sus ingresos y costos (fijos y variables), lo que le permitirá identificar matemáticamente su punto de equilibrio y definir metas de ventas alineadas a la demanda prevista.

De igual forma, el propósito analítico es ayudar a la gerencia a identificar en qué etapa de producción se encuentra la panadería, evitando tomar decisiones perjudiciales, como contratar más trabajadores cuando el producto marginal indique rendimientos decrecientes o negativos.

Finalmente, se busca salvaguardar la información histórica y confidencial del negocio centralizándola en una base de datos relacional segura con capacidad de generar respaldos periódicos.

Etapas de la Formación de la Empresa

  • • Capacitación Empresarial: Realizar talleres prácticos con el personal administrativo y operativo para asegurar una transición fluida hacia el nuevo sistema. Se utilizará y socializará la Versión 1.1 del "Manual de usuario" oficial, capacitando en las 5 pestañas clave: Inventario, Ventas, Cuentas por pagar, Clientes y Proyecciones.
  • • Fomentar la cultura de aprendizaje continua: Integrar un agente de Inteligencia Artificial (IA) de asistencia interna, capaz de responder dudas referentes al manejo del sistema en tiempo real y guiar a los usuarios (por ejemplo, recordar que el consumo de ingredientes debe registrarse como "Salida" manual o que carritos sin confirmar se descartan)[ 47, 48].
  • • Fomento a adquirir nuevos conocimientos, habilidades y competencias: Incentivar a los empleados administrativos a interpretar indicadores microeconómicos (PFT, PFM, PFMg) y capacitar al personal técnico en la administración y creación de respaldos (`.bak`) en SQL Server Management Studio (SSMS).

BASE LEGAL Y CONDICIONES DE USO

En Guatemala, el sistema resguarda NIT, nombres, ventas y existencias. Se debe usar acceso autorizado y no divulgar información del negocio.

  • Constitución (Art. 24): Protege correspondencia, documentos y libros; registros tributarios sujetos a la ley.
  • Código de Comercio (Dto. 2-70, Art. 368): Obligaciones de contabilidad organizada. El sistema apoya el registro diario, mas no reemplaza libros oficiales.
  • Código Tributario (Dto. 6-91) y Ley del IVA (Dto. 27-92): El programa no emite facturas electrónicas ni valida NIT en la SAT; procesos fiscales van por vía oficial.

TECNOLOGÍA DEL PROYECTO

La tecnología del proyecto encarna los principios de una lógica ordenada y metódica para abordar la producción panadera de forma eficiente en la panadería El Horno de la Dos[ 59]:

  • Desarrollado en C# y entorno de ejecución .NET 8 desktop como programa de Windows Forms en tres capas (Entidades, Lógica de Negocio y Presentación), e incluye la DLL de un agente de Inteligencia Artificial[ 59].
  • Base de datos Panadería en SQL Server Express (instancia SQLEXPRESS01) con instrucciones T-SQL, tablas master/detail y procedimientos almacenados (`CrearProducto`, `MoverStock`, `GuardarCliente`, `RegistrarVenta`, `AbonarCuenta`, `RegistrarProduccion`)[ 59].
  • El programa de gráficas incorporado en la ventana principal (`Panaderia.exe`) permite estimar matemáticamente:
    • • Producto Físico Total: PFT = Q
    • • Producto Medio: PFM = Q / L
    • • Producto Marginal: PFMg = ΔQ / ΔL
    • • Punto de Equilibrio: CF / (Precio - (CV / Q))

Impacto y Optimización: La gerencia migra de decisiones empíricas a decisiones estratégicas basadas en datos exactos. Coordina a los 20 empleados en turnos rotativos, mejora la comunicación intercomunitaria y previene la contratación ineficiente al identificar etapas de rendimientos decrecientes.

  • El módulo de Proyecciones vincula el funcionamiento de la panadería con conceptos de Microeconomía, mediante el cálculo del producto físico total, medio y marginal, las etapas aproximadas de producción y el punto de equilibrio[ 61].

  • La arquitectura de tres capas y el almacenamiento en SQL Server Express proporcionan una estructura organizada para el mantenimiento del sistema y la incorporación de mejoras futuras[ 61].
